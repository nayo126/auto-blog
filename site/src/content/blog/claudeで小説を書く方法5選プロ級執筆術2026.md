「小説を書きたいけれど、プロットが思いつかない」「書き始めても途中で詰まってしまう」——そんな悩みを抱えている人は多いはずです。実は今、Claudeを使って小説を執筆するクリエイターが急増しており、Kindle出版やWeb小説サイトで成果を出す例も珍しくなくなりました。

結論からお伝えすると、Claudeは長文の文脈保持力と日本語表現の自然さで、小説執筆に最適なAIの一つです。本記事では、Claude Sonnet 4.6を活用した小説の書き方を5つの工程に分けて、具体的なプロンプトと共に解説します。

## なぜ小説執筆にClaudeが選ばれるのか

数あるAIツールの中で、なぜClaudeが小説執筆に向いているのか。理由は大きく3つあります。

第一に、**長文コンテキストの保持力**です。Claude Sonnet 4.6は最大200Kトークン（日本語で約15万字相当）を扱えるため、長編小説の世界観設定やキャラクター情報を保持したまま執筆を進められます。短編であれば一度のセッションで全体を見渡しながら書けるのが大きな強みです。

第二に、**日本語の自然さ**。ChatGPTと比較しても、Claudeの日本語は翻訳調になりにくく、地の文や会話文の表現が滑らかです。特に心理描写や情景描写では、AI特有の不自然さが少ない出力が得られます。

第三に、**指示への忠実度の高さ**。「ですます調で」「三人称視点で」「ハードボイルド風に」といった文体指定を、長文出力でも崩さずに維持します。海外のRedditの執筆コミュニティでも、Claudeを「最も従順な小説アシスタント」と評価する声が目立ちます。

## 工程1：プロット作成は「三幕構成」で依頼する

小説執筆の最初の壁はプロット設計です。Claudeに丸投げするのではなく、構造を指定して依頼するのがコツです。

おすすめは古典的な「三幕構成」での依頼。以下のようなプロンプトが効果的です。

```
以下の要素で短編小説のプロットを三幕構成で作ってください。
- ジャンル：SFミステリー
- 主人公：30代の女性プログラマー
- 舞台：2045年の東京
- テーマ：記憶の改ざん

第一幕（状況設定）、第二幕（葛藤と転換点）、第三幕（解決）の
各幕を300字程度で出力してください。
```

このように要素を明確に伝えると、Claudeは破綻のない物語構造を提示してくれます。出力されたプロットに対して「第二幕の転換点をもっと劇的にして」「主人公の動機を弱者救済から復讐に変えて」と修正指示を重ねていくことで、自分だけのオリジナルプロットに育てられます。

ポイントは、最初から完璧を求めないこと。3〜5回のやり取りでブラッシュアップする前提で進めると、満足度の高いプロットが完成します。

## 工程2：キャラクター設計は「履歴書形式」で深堀り

魅力的なキャラクターは小説の生命線です。Claudeに人物設定を作らせる時は、履歴書のような項目を指定すると深みが出ます。

具体的には、氏名・年齢・職業といった基本情報に加えて、「幼少期のトラウマ」「最も恥ずかしかった経験」「絶対に譲れない価値観」「口癖」「好きな食べ物と嫌いな食べ物の理由」まで掘り下げてもらいます。

```
主人公のキャラクター設定を以下の項目で作成してください。
表面的な情報だけでなく、行動原理がわかる深い内面まで描いてください。

【基本】氏名/年齢/職業/外見
【内面】価値観/トラウマ/コンプレックス
【習慣】口癖/朝のルーティン/休日の過ごし方
【人間関係】親との関係/恋愛観/友人の数
```

こうして作ったキャラクターシートを毎回プロンプトの冒頭に貼り付けることで、Claudeはキャラクターの言動を一貫させてくれます。途中で性格がブレる現象を防げるため、長編執筆では必須のテクニックです。

## 工程3：本文執筆は「シーン単位」で書かせる

いきなり「第1章を書いて」と頼むと、抽象的で薄い文章になりがちです。代わりに、シーン単位で具体的に依頼しましょう。

たとえば「主人公が深夜のオフィスで不審なログを発見する場面を、五感を使って600字で描写して」というように、**場面・感覚・文字数**の3点を必ず指定します。

さらに精度を上げるなら、以下の要素を追加します。

- **視点**：「一人称」「三人称限定視点」「神視点」など
- **テンポ**：「短文を多用してスピード感を出す」「長文で心理描写を厚く」
- **読後感**：「不穏な余韻を残して終わる」「希望を感じさせる」

書き上がった文章に対しては「比喩表現を3つ追加して」「会話文を増やして地の文を減らして」と部分修正を依頼できます。Claudeは局所的な書き換えが得意なので、人間が全体構成を握りつつ細部を任せる分業が最も効率的です。

## 工程4：会話文は「キャラの語彙リスト」を渡す

小説の質を分けるのが会話文です。Claudeに自然な会話を書かせるには、事前にキャラごとの「語彙リスト」を渡しておくと効果絶大です。

たとえば、知的な研究者キャラなら「論理的には」「興味深いね」「仮説として」といった頻出フレーズを5〜10個リスト化。乱暴な少年キャラなら「うっせえな」「だりい」「マジかよ」など、語尾や口癖をまとめておきます。

```
以下の語彙リストを使い分けて、AとBの会話を800字で書いてください。

A（冷静な刑事）：「なるほど」「興味深い」「論理的には」「失礼ですが」
B（直情型の容疑者）：「うっせえ」「知らねえよ」「ふざけんな」「マジで」

シチュエーション：取調室での初対面、Bは無実を主張している
```

この方法を使うと、キャラの個性が会話だけで伝わる「読ませる対話」が生まれます。地の文の説明に頼らないので、テンポも良くなります。

## 工程5：推敲は「赤入れ役」として使う

書き終わった原稿の推敲こそ、Claudeの真価が発揮される工程です。自分で書いた文章を貼り付けて、編集者役として赤入れしてもらいます。

効果的なプロンプトは以下の通り。

```
以下の小説原稿を編集者として推敲してください。
- 冗長な表現を削除して引き締める
- 同じ語尾の連続を指摘
- 説明過多な箇所を「見せる」描写に書き換え提案
- 文章のリズムが悪い箇所を指摘

ただし、原作者の文体は尊重し、過度な書き換えはしない。
```

注意点は、**全面書き換えを許さない**こと。「あなたの文体に寄せて」と一言加えるだけで、不必要な改変を抑えられます。指摘箇所だけ受け入れて、最終判断は人間が下す——この姿勢を保つことで、AI任せの没個性な文章を避けられます。

## まとめ：Claudeは「共著者」として使うのが正解

Claudeで小説を書く5つの工程を紹介しました。プロット設計、キャラ設計、シーン執筆、会話文、推敲——どの工程でも、人間が方向性を握り、Claudeに具体作業を任せる分業が最も成果を出します。

重要なのは、Claudeを「ゴーストライター」ではなく「共著者」として扱う姿勢です。アイデアと判断は自分、表現の引き出しはClaude。この役割分担を守れば、執筆スピードを3〜5倍に上げながら、自分らしい作品を残せます。まずは短編一本から、試してみてください。

## よくある質問

### Claudeで書いた小説をKindle出版しても著作権は大丈夫ですか？

AI生成文の著作権は法整備が進行中ですが、Amazon KDPは2023年からAI利用の申告を義務化しています。出版時に「AI生成」か「AI支援」かを選択し、最終的に人が加筆修正すれば実務上問題なく出版できます。

### Claudeで小説を書くのは無料プランでもできますか？

無料プランでも執筆可能ですが、1日の利用回数とコンテキストに制限があります。長編を継続的に書くなら月20ドルのProプラン推奨で、200Kトークン（約15万字）の文脈保持を活かせます。

### Claudeで書いた文章はAI判定ツールでバレますか？

GPTZeroなどの判定ツールで検出される可能性はあります。地の文を自分の言葉で書き換える、会話文に口癖を足す、構成を入れ替えるなど人の手を3割以上加えると検出率が大きく下がります。

### ClaudeとChatGPTは小説執筆ならどっちがいい？

日本語の自然さと長文の文脈保持はClaudeが優位で、地の文や心理描写が翻訳調になりにくいです。一方プロット出しのアイデア量やプラグイン連携はChatGPTが強く、構想はChatGPT、執筆はClaudeの併用も有効です。
