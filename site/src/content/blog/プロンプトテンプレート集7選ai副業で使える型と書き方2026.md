「AIに指示を出しても、なんだか思った通りの答えが返ってこない」。ChatGPTやClaudeを開いたものの、毎回ゼロから文章を考えて、結局時間だけが過ぎていく。そんな経験はないでしょうか。

実は、成果を出している人ほど「毎回考えていない」のが現実です。使い回せる型、つまりテンプレートをいくつか持っておき、状況に合わせて穴埋めしているだけ。この記事では、そのまま使える7つのプロンプトテンプレートを実例付きで紹介します。

結論から言うと、プロンプトは「役割→前提→指示→制約→出力形式」の5要素を埋めるだけで質が跳ね上がります。理由は、AIが迷う余地を消せるから。以下、副業の現場でそのまま流用できる型を順に見ていきます。

## なぜテンプレート集が必要なのか

結論：再現性のある成果を出すには、毎回ひらめきに頼らず「型」を回すのが最短です。

AIの出力品質は、入力の構造化レベルにほぼ比例します。海外のプロンプト研究コミュニティでも、曖昧な一文の指示より、役割や制約を明示した指示の方が出力の有用性が大きく上がるという報告が繰り返し共有されています。感覚的にも、上司に「いい感じにやって」と言われるより「A4一枚、3つの要点、来週月曜まで」と言われた方が動きやすいのと同じです。

特にAI副業では、同じ作業を何十回も繰り返します。たとえばブログ記事のリライト、商品説明文の作成、SNS投稿の量産。ここで毎回プロンプトを考え直していたら、1件あたり10分のロスが100件で約17時間の差になります。テンプレートを用意しておけば、変数の部分だけ差し替えて即実行できる。

そして見落とされがちなのが「品質のブレが消える」こと。テンプレートに沿えば、調子の良い日も悪い日も一定水準の出力が得られます。クライアントワークで納品物の質を安定させたいなら、ここが一番効いてきます。

## 全テンプレートに共通する5つの骨格

結論：どんな用途でも、次の5要素を埋めれば外しません。

1. **役割（Role）**：「あなたはプロのコピーライターです」など、AIに立場を与える
2. **前提（Context）**：読者層、目的、背景情報を渡す
3. **指示（Task）**：具体的に何をしてほしいか
4. **制約（Constraints）**：文字数、トーン、禁止事項
5. **出力形式（Format）**：箇条書き、表、見出し付きなど

この骨格をひとつのテンプレートにすると、こうなります。

```
# 役割
あなたは{専門分野}のプロです。

# 前提
- 対象読者：{誰に向けてか}
- 目的：{何を達成したいか}

# 指示
{やってほしいこと}を作成してください。

# 制約
- 文字数：{xxx字}
- トーン：{丁寧/カジュアルなど}
- 禁止：{避けたい表現}

# 出力形式
{箇条書き/表/見出し付き本文}
```

ChatGPT 5でもClaude Sonnet 4.6でも、この型はそのまま機能します。両者ともシステム的な指示の理解度が高く、見出し（#）で区切ると各ブロックを正確に解釈してくれるからです。逆に言えば、ここを地の文で長々書くと精度が落ちます。まずはこの5ブロックを暗記してしまうのが近道です。

## 副業で稼働する実用テンプレート7選

ここからは用途別に、コピペして変数を埋めるだけの7本を紹介します。

### 1. ブログ記事の構成案づくり

```
あなたはSEOに強い編集者です。
キーワード「{KW}」で検索する人の悩みを3つ挙げ、
それを解決するH2見出しを5本、各見出しの要点を1行で提案してください。
```

### 2. 文章のリライト（トーン変換）

```
以下の文章を、{20代向けのカジュアルなトーン}に書き換えてください。
意味は変えず、専門用語は残したまま、堅さだけ取り除いてください。
---
{元の文章}
```

### 3. 商品・サービスの説明文

```
あなたはセールスコピーのプロです。
商品名：{名前}／特徴：{3つ}／ターゲット：{誰}
この情報から、ベネフィット先行で200字の説明文を3パターン作ってください。
```

### 4. SNS投稿の量産

```
テーマ「{テーマ}」について、保存されやすいX投稿を5本。
1本140字以内、1行目にフックを置き、絵文字は使わないでください。
```

### 5. アイデア出し（壁打ち）

```
{ジャンル}の副業アイデアを10個。
初期費用1万円以内、スマホだけで始められる条件で、
それぞれ「想定収益」と「最初の一歩」を添えてください。
```

### 6. 要約・情報整理

```
以下の長文を、忙しい人向けに3行で要約し、
そのあとに重要ポイントを5つ箇条書きにしてください。
---
{長文}
```

### 7. 添削・フィードバック

```
あなたは厳しい校閲者です。
以下の文章の弱い点を3つ指摘し、改善案も添えてください。
褒める必要はありません。
---
{文章}
```

この7本があれば、ライティング系の副業作業の8割はカバーできます。まずは自分の仕事に近い1〜2本をブックマークやメモアプリに保存し、変数だけ埋めて回してみてください。

## テンプレートの精度をさらに上げる3つのコツ

結論：型を持ったうえで、次の3点を足すと出力が一段階洗練されます。

**ひとつ目は「具体例を1つ渡す」こと。** 「こういう感じで」と完成イメージを1例示すだけで、AIはトーンや粒度を一気に掴みます。これはワンショットと呼ばれる手法で、抽象的な指示を10行足すより、良い例を1つ見せる方が効きます。

**ふたつ目は「ダメな例も渡す」こと。** 「次のような表現は避けてください」とNG例を添えると、ありがちな失敗を先回りで防げます。たとえばSNS投稿で「いかがでしたか?」のような定型句を出させたくないなら、明示的に禁止する。制約はポジティブな指示よりネガティブな指示の方が守られやすい場面が多くあります。

**みっつ目は「段階的に出させる」こと。** いきなり完成品を求めず、「まず構成案だけ→OKなら本文」と分けると、途中で軌道修正できます。Claudeの拡張思考やChatGPTの推論機能を使う場合も、最初に方針をすり合わせてから本番に入る方が、結果的にやり直しが減ります。

そして全テンプレートに共通する地味だが重要な点として、出力が気に入らなかったら「3パターン出して」と複数案を要求すること。1発勝負にせず選べる状態を作るだけで、採用できる確率が体感で大きく変わります。

## まとめ

プロンプトは才能ではなく、型と運用の問題です。「役割→前提→指示→制約→出力形式」の5骨格を覚え、今回の7テンプレートを自分用に保存しておけば、AI副業の作業時間は確実に圧縮できます。

まずは1本、自分の仕事に近いテンプレートを今日コピーして、変数を埋めて回してみてください。使いながら自分仕様に書き換えていくことが、再現性のある成果への一番の近道になります。
