「AntigravityとClaude Code、結局どっちを選べばいいのか分からない」——そう感じている人は多いはずです。2025年11月に発表されたGoogleのAntigravityは、ブラウザ・ターミナル・エディタを横断する“エージェント中心”のIDEとして話題を集めました。一方でClaude Codeは、Anthropicが提供するターミナル特化の開発エージェントとして、副業エンジニアやノーコード勢から熱い支持を得ています。

本記事では、料金・自律性・コード品質・学習コスト・副業適性の5軸で両者を比較し、AI副業を始めたい20-30代がどちらを選ぶべきかを整理しました。

## 結論:副業ならClaude Code、本格開発ならAntigravity

結論から書きます。**月数万円のAI副業を最短で始めたいならClaude Code、複数エージェントで本格的なWebアプリ開発を回したいならAntigravity**が向いています。

理由はシンプルで、Claude Codeは「ターミナルに張り付くだけで仕事が終わる」軽さがあり、副業の細切れ時間でも回しやすい設計です。対してAntigravityは、エディタ・ブラウザ・ターミナルの三面を同時にエージェントが操作する“マネージャー型”で、要件定義から検証まで任せられる代わりに、セットアップとプロジェクト設計に時間がかかります。

両者は競合というより役割が違うツールで、副業フェーズに応じて使い分けるのが最適解です。

## 料金とプランの違い

料金体系は両者で大きく異なります。

- **Claude Code**:Anthropicの「Claude Pro($20/月)」「Max($100または$200/月)」のサブスクに含まれる形で利用可能。API従量課金でも使え、Sonnet 4.6なら入力$3/百万トークン前後。
- **Antigravity**:Google AI Pro / Ultra に紐づき、無料ティアでもGemini 3 ProとClaude Sonnet 4.5を利用可能(レート制限あり)。本格運用はUltra($249.99/月)が前提。

副業初期の「月3,000円〜2万円で始めたい層」にはClaude Code Proが現実的です。Antigravityは無料枠が手厚い反面、本気で使うとUltra課金が必要で、月3万円超のコストが発生します。月収が10万円を超えてから移行するのが安全です。

## 自律性とエージェント設計の比較

ここが両者の思想がもっとも分かれるポイントです。

Antigravityは**マルチエージェント前提**で、複数のエージェントが並列でタスクを進めるWorkspaceを中心に据えています。Manager画面でタスクを分解し、各エージェントがブラウザ操作・コード生成・テストを担当する“チーム開発”モデルです。海外のレビューでは「PMがいなくても要件から実装まで走り切る」と評価されています。

一方Claude Codeは**シングルエージェント+SDK拡張**型で、ターミナル1つで完結します。Sub agentsやSkillsという仕組みでタスクごとに専門役を呼び出せますが、基本は対話のリズムが軸です。1人で集中して書くスタイルに馴染みやすく、人間が制御を握り続けたい人に向いています。

## コード品質と検証機能

コード生成精度は2026年5月時点でほぼ拮抗しています。

- Antigravityは内部でClaude Sonnet 4.5・Gemini 3 Pro・GPT-5.1などを切り替え可能で、ブラウザ自動操作とスクショ確認まで含めた“動作検証付きの納品”が強み。
- Claude Codeは最新のOpus 4.7(1M context)を活用でき、長文の既存コード読解・大規模リファクタで頭一つ抜けています。

副業で多い「LP制作・小規模Webアプリ・スクリプト自動化」程度であれば、Claude Codeの一発精度で十分です。E2Eテストが必要なSaaS開発まで踏み込むなら、Antigravityのブラウザ統合が効いてきます。

## 副業活用度と学習コスト

最後に副業視点での評価です。

| 項目 | Claude Code | Antigravity |
| --- | --- | --- |
| 学習時間目安 | 1〜3時間 | 8〜15時間 |
| 案件単価レンジ | 5,000〜5万円/件 | 5万〜30万円/件 |
| 向いている案件 | スクリプト、修正、LP | フルスタックWeb開発 |
| ノーコード勢の参入 | ◎ | △ |

Claude Codeはターミナルに慣れていない人でも、最初の30分で「ファイル一覧見せて」「このバグ直して」だけで価値を出せます。一方Antigravityは概念(Workspace/Artifact/Verification)の学習が必要で、案件単価は高いものの、初学者がいきなり挑むとセットアップで止まりがちです。

副業デビューから3ヶ月はClaude Code、月収10万円を超えてから案件単価を上げるためにAntigravityへ拡張、というロードマップが現実的です。

## まとめ

AntigravityとClaude Codeは、同じ“AI開発エージェント”でも狙う場所が違います。**最短で副業収益を作るならClaude Code、複数案件を捌くチームを作りたいならAntigravity**——これが2026年5月時点の答えです。

迷ったらまずClaude Code Proで1ヶ月試し、扱える案件規模が頭打ちになってからAntigravityへ移行しましょう。ツールに振り回されるのではなく、稼ぐフェーズに合わせて選び直すことが、AI副業を伸ばす最短ルートです。

## よくある質問

### Antigravityは無料で使えますか?

Antigravityは2025年11月のパブリックプレビュー時点で無料公開されており、Gemini 3 ProとClaude Sonnet 4.5を回数制限付きで利用できます。商用利用や上限緩和は今後の有料プランで段階的に提供される見込みです。

### Claude Codeの月額料金はいくらですか?

Claude CodeはClaude Proの月20ドルプランから利用でき、より多くの利用枠が必要なら月100ドルのMaxプラン、ヘビーユーザー向けは月200ドルのMax 20xプランがあります。API従量課金での利用も可能です。

### プログラミング初心者でもClaude Codeは使えますか?

ターミナル操作の基礎(cd・ls程度)が分かれば初心者でも1日で扱えます。自然言語で「このバグを直して」と指示するだけで動くため、HTML/CSSレベルの知識からでも副業案件の納品が可能です。

### AntigravityとCursorはどちらが優秀ですか?

コード補完の速さはCursorが優位ですが、複数エージェントによる自律タスク実行はAntigravityが上です。月20ドルのCursorに対しAntigravityは無料プレビュー中なので、エージェント型開発を試すならAntigravityが有利です。
