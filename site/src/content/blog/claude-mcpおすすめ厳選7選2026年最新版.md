## そもそもClaude MCPとは何か

<!-- INLINE_IMG -->
![Claude MCPおすすめ厳選7選｜2026年最新版 - そもそもClaude MCPとは何か](/auto-blog/inline-images/claude-mcp-7-2026--0.jpg)


MCP(Model Context Protocol)は、Anthropicが2024年末に公開したオープン規格で、Claudeのような大規模言語モデルと外部ツールを安全につなぐ共通プロトコルです。従来は各AIが独自のプラグイン仕様を持っていましたが、MCPによって「一度作れば複数のAIで動く」という標準化が進みました。

Claude Desktopアプリでは設定ファイル(`claude_desktop_config.json`)にMCPサーバーを記述するだけで、対話中にClaudeが自動的にツールを呼び出してくれます。たとえばGitHub MCPを入れておけば「先週マージしたPR一覧を出して」と話しかけるだけで、Claudeがリポジトリを参照して回答します。

ポイントは**ローカル実行が基本**であること。データが第三者サーバーを経由しないため、機密情報を扱う副業や本業の補助業務でも比較的安心して使えます。一方で、サーバーの選定と権限管理は自己責任になるので、本記事の選び方を参考にしてください。

## おすすめMCPサーバー厳選7つ

<!-- INLINE_IMG -->
![Claude MCPおすすめ厳選7選｜2026年最新版 - おすすめMCPサーバー厳選7つ](/auto-blog/inline-images/claude-mcp-7-2026--1.jpg)


結論から書くと、AI副業や個人作業で本当に役立つMCPは次の7つです。順番に解説します。

### 1. Filesystem MCP

ローカルのフォルダをClaudeに読み書きさせる定番サーバー。記事の下書きフォルダや画像ストックを指定すれば、ファイル名検索からリライト、フォルダ整理まで自然言語で指示できます。導入5分、副業初心者の最初の一本に最適です。

### 2. GitHub MCP

リポジトリ、Issue、PRをClaudeから直接操作できます。コード生成だけでなく「未対応Issueをラベル別に集計」「READMEを最新コミットに合わせて更新」といった作業が一気に片付きます。エンジニア副業をしている人なら必須です。

### 3. Notion MCP

データベース連携が強力。ブログ案件のタスク管理、クライアント情報、リサーチメモをまとめてClaudeに渡せます。「今週締切のタスクだけ抽出してSlackに投げる文面を作って」のような複合指示が一発で通ります。

### 4. Google Drive MCP

スプレッドシートとドキュメントを横断検索。請求書テンプレや過去の提案書を参照しながら、新規ドキュメントを下書きさせる用途で活きます。

### 5. Slack MCP

DMやチャンネル履歴を要約し、返信文を提案。コミュニティ運営やオンラインサロン副業との相性が抜群です。

### 6. Brave Search MCP

Web検索を組み込めるMCP。リサーチ系の作業でハルシネーション(誤情報生成)が激減します。海外のRedditでも「ChatGPTのWeb閲覧より精度が安定する」との報告が増えています。

### 7. Playwright MCP

ブラウザ自動操作。フォーム入力、価格調査、スクレイピング系のルーチン作業をClaudeに任せられます。

## 失敗しない選び方の3原則

MCPを入れすぎると、Claudeが毎回ツール選択に迷い、応答速度が落ちます。次の3原則で絞りましょう。

**原則1：自分の作業ログから選ぶ**
過去1週間で繰り返した作業を3つ書き出し、それを自動化できるMCPだけを入れます。やみくもに公式マーケットプレイスから人気順で選ぶのは失敗のもとです。

**原則2：書き込み権限は最小限に**
Filesystem MCPなら、ホームディレクトリ全体ではなく作業用フォルダ1つだけを指定する。GitHub MCPはPublicリポジトリのみ読み取り、といった粒度で設定します。

**原則3：公式または有名OSSを優先**
野良MCPサーバーには認証トークンを抜き取る悪意ある実装の報告もあります。Anthropic公式リポジトリ、または星数1000以上のOSSから選ぶのが無難です。

## 導入手順とつまずきポイント

Claude Desktopを起動し、メニューから「Settings」→「Developer」→「Edit Config」を開きます。`claude_desktop_config.json`にサーバー情報をJSONで追記し、アプリを再起動するだけで反映されます。

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/yourname/work"]
    }
  }
}
```

よくあるつまずきは3つ。1つ目はNode.jsが入っていないケース。`npx`コマンドが動かないと全MCPが起動しません。2つ目は絶対パスの記述ミス。Windowsならバックスラッシュのエスケープを忘れがちです。3つ目はトークンの管理。GitHubやNotionのアクセストークンはJSONに直書きせず、環境変数経由で渡すのが安全です。

導入後はClaudeとの会話で「使えるツール一覧を見せて」と聞けば、認識されているMCPが表示されます。表示されない場合は設定ファイルの構文エラーを疑ってください。

## 副業に直結する活用パターン3つ

**パターン1：ブログ運営フルスタック**
Filesystem + GitHub + Notionの3点セット。記事構成案をNotionで管理し、原稿はローカルのMarkdownファイルで執筆、公開はGitHubへのプッシュで完結します。Claudeに「今週の記事3本のSEOチェックをして」と頼めば、ファイルを横断的に確認してくれます。

**パターン2：クライアントワーク自動化**
Google Drive + Slack + Notion。提案書のたたきをDriveから引っ張り、Slackのやり取りを要約し、Notionに議事録を残す流れを自然言語で指示できます。

**パターン3：リサーチ業務の高速化**
Brave Search + Playwright + Filesystem。競合調査やキーワード調査を1時間かかっていた作業が15分程度に短縮できたという声もあります。月5万円規模の調査案件なら、利益率が一気に変わります。

## まとめ：まずは2つ入れて使い倒す

Claude MCPは「全部入り」ではなく「必要最小限」が正解です。まずはFilesystemと、自分の業務に最も近いもう1つだけを導入し、1週間使い倒してみてください。

体感として作業時間が3割縮まれば、追加のMCPを検討するタイミングです。AI副業の競争は2026年も激化していますが、MCPを使いこなしている人とそうでない人の差は今後さらに開きます。今日のうちに設定ファイルを開いて、最初の一歩を踏み出しましょう。

## よくある質問

### Claude MCPの導入は無料でできますか？

MCPサーバー自体はオープン規格で無料です。GitHubやNotionなど連携先のAPI利用も基本無料枠で始められます。ただしClaude Pro(月20ドル)やAPI従量課金は別途必要で、本格運用なら月20〜30ドルが目安です。

### Claude MCPサーバーの設定はどこで行いますか？

Claude Desktopアプリの設定ファイル(claude_desktop_config.json)にサーバー情報を記述します。Mac版なら~/Library/Application Support/Claude/に配置し、保存後アプリを再起動すれば連携が反映されます。

### Claude MCPとChatGPTのプラグインは何が違いますか？

MCPはAnthropicが公開したオープン規格で、一度作れば他のAIでも再利用できます。ChatGPTのプラグインはOpenAI独自仕様のため移植性が低く、MCPは外部ツール連携の汎用性とセキュリティ設計で優れています。

### MCPサーバーは何個まで同時に使えますか？

技術的な上限はなく、設定ファイルに記述すれば10個以上の同時接続も可能です。ただし数が増えると処理が重くなるため、副業用途では3〜5個に絞ると応答速度と管理のバランスが取れます。
