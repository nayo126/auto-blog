1時間のインタビュー音声を、手作業で文字起こししたことはありますか。普通にやれば4〜5時間。再生して止めて、巻き戻して、また打ち込む。あの地獄のような作業を、ほぼ無料で数分に縮められるとしたら。

それを可能にするのが、OpenAIが公開した音声認識AI「Whisper」です。海外では文字起こしや字幕制作の現場で標準ツールになりつつあり、日本でも副業のネタとして注目され始めています。

この記事では、Whisperが何者なのか、無料とAPIどちらで使うべきか、そして実際にお金につなげる5つの方法を具体的に解説します。

## 結論：Whisperは「無料で動く高精度な文字起こしAI」

結論から言うと、OpenAI Whisperは自分のパソコンで無料動作する音声認識(ASR)モデルです。理由は、2022年9月にMITライセンスのオープンソースとして公開されたから。つまり誰でもダウンロードして、API料金ゼロで使えます。

特徴を整理すると次の通りです。

- **約68万時間の音声**で学習され、雑音やなまりに強い
- **日本語を含む約99言語**に対応、英語への翻訳も同時にできる
- モデルは tiny / base / small / medium / large の5サイズ
- `large-v3`(最新の大型版)なら専門用語の精度も実用レベル

無料で使えるとはいえ、large系を快適に動かすにはそれなりのPCスペックが要ります。手持ちのマシンが非力なら、後述のAPI版を選ぶほうが現実的です。

## 無料版とAPI版、どっちを選ぶべきか

選択を迷う人が多いので、判断軸をはっきりさせます。結論は「処理量が多くPCが強いなら無料版、手軽さ優先ならAPI版」です。

| | オープンソース版 | API版 |
|---|---|---|
| 料金 | 無料 | whisper-1で1分あたり約$0.006 |
| 必要なもの | GPU推奨のPC・Python環境 | APIキーだけ |
| 速度 | PC性能次第 | サーバー処理で安定 |
| 向く人 | 大量処理・コスト重視 | すぐ試したい・少量 |

たとえば1時間の音声をAPIで処理しても、料金はおよそ$0.36(約55円前後)。月に何十本も回すなら自前のPCで無料運用、たまにしか使わないならAPIが手軽です。

2025年にはOpenAIから`gpt-4o-transcribe`など新しい音声認識モデルも登場し、精度はさらに上がりました。ただし副業の実務レベルでは、無料のWhisper本体でも十分戦えます。

## ステップで分かる無料Whisperの始め方

「プログラミング未経験だと無理では」と身構える必要はありません。Pythonが入っていれば、コマンドは数行です。

```bash
pip install -U openai-whisper
whisper audio.mp3 --model small --language Japanese
```

この2行で、音声ファイルと同じ場所にテキストや字幕ファイル(.srt / .vtt)が出力されます。手順をまとめると、

1. PythonとFFmpegをインストールする
2. `pip install`でWhisperを導入する
3. 文字起こししたい音声・動画ファイルを用意する
4. モデルサイズを指定して実行する(まずは`small`が速度と精度のバランス良)

コードを書きたくない人は、Whisperを組み込んだGUIアプリや、ブラウザで動くサービスを使えば、ファイルをドラッグするだけで完結します。まずは5分の短い音声で試して、出力の質を体感するのがおすすめです。

## Whisperで稼ぐ5つの副業アイデア

ここが本題です。Whisperを使った収益化の入り口を5つ挙げます。

- **文字起こし代行**：クラウドソーシングでは音声1分あたり数十円〜の案件が常にあります。Whisperで下書きを作り、人の耳で誤変換を直すだけで時給を大きく上げられます。
- **YouTube字幕・ショート制作**：動画の音声から`.srt`字幕を自動生成。字幕付き動画の編集代行は単価が安定しています。
- **議事録・インタビュー記事化**：会議やインタビュー音声をテキスト化し、ChatGPTで整形すれば記事の素材が一気に揃います。
- **ポッドキャストのブログ化**：海外の事例として、音声番組を全文テキスト化してSEO記事に転用し、検索流入を伸ばす手法が広く使われています。
- **多言語字幕での横展開**：翻訳機能を組み合わせ、日本語動画に英語字幕を付けて海外向けに発信する使い方もあります。

ポイントは、Whisperの出力を「完成品」ではなく「下書き」と捉えること。最後の校正という人の手が入るからこそ、お金を払う価値が生まれます。AIで8割を自動化し、残り2割の品質で差をつける。これが現実的な勝ち筋です。

## まとめ：まず5分の音声で試そう

OpenAI Whisperは、無料で動く高精度な音声認識AIです。99言語対応で、自分のPCでもAPIでも使え、文字起こし代行から字幕制作まで副業の幅を一気に広げてくれます。

大切なのは、完璧を目指して情報収集ばかりするより、手元の短い音声を1本流してみること。出力の精度を体感すれば、自分に合った収益化の道筋が見えてきます。今日の5分が、来月の数万円につながります。
